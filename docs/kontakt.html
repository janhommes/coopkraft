Kontakt

CoopKraft ist ein offenes Projekt. Fragen, Ideen und Fehler besprechen wir öffentlich auf GitHub, damit alle Genossenschaften etwas davon haben.

  • Fehler gefunden oder eine Idee? Legt ein Issue an und beschreibt, was passiert ist oder was ihr euch wünscht.
  • Selbst einsetzen: Die Einrichtungsanleitung führt Schritt für Schritt zur eigenen Installation.
  • Mitentwickeln: Pull Requests sind willkommen.

Für ein Issue braucht ihr ein kostenloses GitHub-Konto.
